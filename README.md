### What I'm working on

- **Paper → Product**, a 10-project series. For each one I read a recent AI paper, reproduce a key result, add something of my own, and ship it with tests, CI/CD and a demo. Each project comes with a video walkthrough.
- **My M.Sc. research**: how stable are the explanations (GNNExplainer, PGExplainer, GNNShap) of graph neural networks that detect money laundering in Bitcoin transactions under extreme class imbalance?
